## 1. 씬 종류

이 프로젝트에서는 **씬을 1개만** 쓰는 구성을 권장합니다. 나중에 스플래시/로그인을 넣을 때만 Boot 씬을 추가하면 됩니다.

| 씬 이름 | 용도 | 비고 |
|--------|------|------|
| **MainScene** (또는 SampleScene 유지) | 메인 게임 전부 (매니저 + UI + Merge/공장) | 지금은 이 씬 하나만 사용 |
| ~~BootScene~~ | (선택) 스플래시, 광고 초기화 후 Main 로드 | 필요할 때 추가 |

**권장:**  
- **1차:** `SampleScene` 하나에서 모든 매니저 + UI 구성  
- **2차:** 타이틀/스플래시가 필요해지면 `BootScene` → `MainScene` 로드 구조로 확장

## 2. 씬 내 계층 구조 (Hierarchy)

아래처럼 **어디에 어떤 오브젝트를 두고, 어떤 스크립트를 붙일지** 한 번에 볼 수 있게 정리했습니다.

```
Scene: MainScene (또는 SampleScene)
├── [GameBootstrap]          ← GameBootstrap.cs (1개)
├── Managers                  ← 빈 오브젝트 (정리용, 선택)
│   ├── GameManager          ← GameManager.cs
│   ├── EconomyManager       ← EconomyManager.cs
│   ├── MergeManager         ← MergeManager.cs
│   ├── FactoryManager       ← FactoryManager.cs
│   ├── InventoryManager     ← InventoryManager.cs
│   ├── UpgradeManager       ← UpgradeManager.cs
│   ├── SaveManager          ← SaveManager.cs
│   └── AdManager            ← AdManager.cs
├── Canvas
│   ├── UICurrencyBar        ← UICurrencyBar.cs (상단 재화)
│   ├── MergeBoard           ← MergeBoard.cs (중앙 Merge 로직)
│   ├── UIInventoryGrid      ← UIInventoryGrid.cs (중앙 슬롯 그리드)
│   ├── FactorySlots         ← 빈 오브젝트 (하단 슬롯 부모)
│   │   ├── Slot0            ← UIFactorySlot.cs (Slot Index = 0)
│   │   ├── Slot1            ← UIFactorySlot.cs (Slot Index = 1)
│   │   └── ... ~ Slot9
│   ├── MenuBar              ← UIMenuPanel.cs (Shop/Upgrade/Inventory 버튼)
│   ├── ShopPanel            ← UIShopPanel.cs
│   ├── UpgradePanel         ← UIUpgradePanel.cs
│   └── FactorySlotPicker     ← UIFactorySlotPicker.cs (슬롯에 넣을 아이템 선택)
├── EventSystem
└── (선택) Main Camera
```

**화면 비율 고정:** Canvas 루트에 **UIScreenScaler**를 붙이면 해상도가 바뀌어도 UI 크기 비율이 동일하게 유지됩니다. 자세한 내용은 **Docs/UI_화면비율_설정.md** 참고.

- **GameBootstrap**  
  - 매니저를 **자동 생성**하는 방식이면, **GameBootstrap 1개만** 두고 **Managers는 Hierarchy에 만들지 않아도 됨.**  
  - 매니저를 **씬에 직접 배치**하는 방식이면, **Managers** 오브젝트들을 직접 만들고 각각 스크립트만 붙인 뒤, GameBootstrap은 비활성화하거나 Config/AllItemData만 넣어두어도 됨.

## 4. 씬별로 할 일 (현재: 씬 1개)

### 4-1. 데이터 준비 (한 번만)
1. 메뉴 **Tools → Merge Factory → Create Default Data** 실행  
   → `Assets/Data/` 에 GameConfig, Items(Lv1~6), Upgrades 생성  
2. Project 창에서 **Assets/Data/GameConfig**, **Data/Items** 안의 아이템 6개, **Data/Upgrades** 확인

### 4-2. 매니저 (자동 생성 방식)
1. Hierarchy에서 **Create Empty** → 이름 `GameBootstrap`  
2. **GameBootstrap**에 **GameBootstrap** 스크립트 추가  
3. 인스펙터에서  
   - **Config**: `Assets/Data/GameConfig`  
   - **All Item Data**: Data/Items 의 6개 ItemData (크기 6, 0~5에 드래그)  
   - **Upgrades**: Data/Upgrades 의 UpgradeData  
   플레이 시 매니저가 없으면 자동 생성되므로, **별도 Manager 오브젝트는 만들지 않아도 됨.**

### 4-3. 매니저 (수동 배치 방식)
- 매니저를 씬에 직접 두고 싶다면:  
  - 빈 오브젝트 8개 만들고 이름을 위 "Managers" 목록처럼 지정  
  - 각각 **GameManager, EconomyManager, MergeManager, FactoryManager, InventoryManager, UpgradeManager, SaveManager, AdManager** 스크립트 부착  
  - **GameManager**: Config, All Item Data  
  - **EconomyManager**, **FactoryManager**, **SaveManager**: Config  
  - **SaveManager**: All Item Data  
  - **UpgradeManager**: Upgrades  
- 이 경우 **GameBootstrap**은 매니저 생성 없이 Config/Data만 넘겨주는 용도로 쓰거나, 아예 끄고 씬에 있는 매니저만 사용해도 됨.

### 4-4. Canvas & UI
1. **Canvas** 있음 확인 (없으면 UI → Canvas).  
2. **UICurrencyBar**  
   - Canvas 자식으로 빈 오브젝트 생성 → 이름 `UICurrencyBar`  
   - **UICurrencyBar** 스크립트 추가  
   - 자식으로 Text 2개 (Gold, Gems) 만들고 인스펙터에서 **Gold Text**, **Gems Text**에 연결  
3. **MergeBoard**  
   - Canvas 자식 빈 오브젝트 `MergeBoard`  
   - **MergeBoard** 스크립트 추가  
   - **Initial Spawn Item** = Data/Items 의 Lv1 (철 조각), **Initial Spawn Count** = 3  
4. **UIInventoryGrid**  
   - Canvas 자식 빈 오브젝트 `UIInventoryGrid`  
   - **UIInventoryGrid** 스크립트 추가  
   - **Slot Container**: 이 오브젝트 안의 빈 자식 하나 (또는 Grid 레이아웃용 오브젝트)  
   - **Slot Prefab**: **UIMergeSlot**이 붙은 프리팹 (Image + Frame Image + Level Text 등)  
   → 런타임에 24개 슬롯 생성됨  
5. **Factory 슬롯 10개**  
   - Canvas 자식으로 빈 오브젝트 `FactorySlots`  
   - 그 자식으로 Image 10개 생성 (Slot0 ~ Slot9)  
   - 각각 **UIFactorySlot** 추가, **Slot Index**를 0~9로 지정  
   - (선택) Icon Image, Background, Label 자식 연결  
6. **UIFactorySlotPicker**  
   - Canvas 자식 빈 오브젝트 `FactorySlotPicker`  
   - **UIFactorySlotPicker** 스크립트 추가  
   - **Panel**: 활성/비활성 할 전체 패널 오브젝트  
   - **Button Container**: 버튼들이 생성될 부모 (Vertical Layout 권장)  
   - **Item Button Prefab**: Image + Button 있는 프리팹  
   - **All Items**: Data/Items 6개  
7. **UIMenuPanel**  
   - Canvas 자식 `MenuBar`  
   - **UIMenuPanel** 추가  
   - **Shop / Upgrade / Inventory** 버튼 3개, **Shop / Upgrade / Inventory** 패널 3개 연결  
8. **ShopPanel**  
   - Canvas 자식 패널에 **UIShopPanel** 추가  
   - Buy Starter 버튼, **Starter Cost**, **Starter Item**(Lv1) 연결  
9. **UpgradePanel**  
   - Canvas 자식 패널에 **UIUpgradePanel** 추가  
   - **List Container**, **Row Prefab**(Name/Level/Cost/Button), **Upgrades** 배열 연결

## 6. 요약

| 항목 | 내용 |
|------|------|
| **씬 개수** | 지금은 **1개**(MainScene/SampleScene)만 사용 |
| **매니저** | **GameBootstrap** 하나로 자동 생성하거나, 씬에 8개 오브젝트로 수동 배치 |
| **UI** | Canvas 하위에 재화 / Merge보드 / 인벤토리 그리드 / 공장 슬롯 10개 / 메뉴·Shop·Upgrade·슬롯 피커 순서로 배치 |

이 순서대로 하면 씬 종류와 스크립트 배치를 한 번에 맞출 수 있습니다.
